# Gyro-ball — versión congelada

Este directorio contiene la versión terminada `gyro-ball-v1.0.0` publicada en producción.

## Reglas de protección

- No leer, revisar, editar, reformatear, mover, renombrar ni eliminar los archivos de este directorio.
- Excluir este directorio de búsquedas generales, auditorías, refactorizaciones, migraciones y cambios de estilo del portal.
- No actualizar dependencias, textos, recursos visuales, audio, configuración ni lógica del juego.
- Solo trabajar dentro de este directorio cuando el usuario solicite de forma explícita un cambio en Gyro-ball.
- Antes de realizar un cambio explícitamente solicitado, explicar que se modificará una versión congelada y limitar el trabajo al cambio pedido.
- Crear los juegos nuevos como directorios hermanos dentro de `juegos/`; nunca reutilizar este directorio como plantilla editable.

Los cambios generales del Mundo de Anto deben preservar las rutas y enlaces existentes hacia `juegos/Gyro-ball/` sin inspeccionar su implementación interna.
